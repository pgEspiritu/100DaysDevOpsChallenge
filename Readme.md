# 100 Days of DevOps 🚀

A hands-on journey to build real **DevOps skills** in just **15–30 minutes a day**.  

This repository documents my daily progress through **Linux, Docker, Kubernetes, Git, CI/CD, and Infrastructure as Code (IaC)** challenges – starting from **Day 1**.  

👉 Learn by doing, and join me as I work toward **DevOps mastery!**  

---

## 📌 Challenge Structure  

- ⏱ **Time commitment**: 15–30 minutes daily  
- 🛠 **Topics covered**: Linux, Git, Docker, Kubernetes, Jenkins, Ansible, Terraform, Cloud, and CI/CD  
- 📖 **Format**: Each day contains a **task**, with notes and scripts
